## Описание

Символьная динамика представляет собой мощный математический аппарат для
исследования сложных нелинейных систем. Одним из инструментов символьной динамики являются kneadings («нидинги») — символьные последовательности, которые характеризуют качественное поведение динамической системы относительно заданного разбиения фазового пространства.

Этот проект позволяет вычислять нидинги в системе четырёх идентичных глобально связанных фазовых осцилляторов с бигармонической связью и визуализировать результаты на карте параметров.

## Установка и запуск

```bash
git clone --recursive https://github.com/Ferikus/kneadings.git
cd <путь к проекту>
python main.py <путь к конфигу формата YAML>
```

## Структура проекта

`kneadings` -- корневая папка проекта  

`config` -- примеры конфигов (основной шаблон находится в `test.yaml`)  

`lib` -- библиотеки проекта  
`lib\eq_finder` -- подмодуль, используемый для работы с системой  
`lib\computation_template` -- подмодуль, используемый для запуска проекта  

`output` -- результаты вычислений

`src` -- исходный код проекта  
`src\system_analysis` -- инструменты для работы с системой, получение начальных условий для запуска нидингов  
`src\cuda_sweep` -- параллельные вычисления с помощью CUDA (нидинги, анализ периода нидингов и др.)  
`src\plotting` -- отрисовка карт режимов и аттракторов  
`src\computing` -- дополнительные материалы для подмодуля `computation_template`, автоматический последовательный запуск всех этапов работы с нидингами и других задач (читать ниже)  
`src\routing` -- исследование маршрутов на картах нидингов  
`src\symmetry` -- исследование типов симметрии аттрактора  

`test` -- другие вспомогательные материалы при разработке и тестировании проекта

`main.py` -- главный файл проекта, который воспроизводит все три этапа конвейера из `src\computing`. Например, в случае задачи `kneadings` это автоматический подсчёт начальных условий, подсчёт нидингов и отрисовка карты режимов

### worker-задачи

Задачи, предназначенные для выполнения на основной вычислительной стадии конвейера.

**Задачи, основанные на нидингах.** Создают карты режимов, на которых цвет каждой точки назначается особым для задачи способом:

`kneadings` -- назначает цвет на основе нидинга в численном виде  
`regularity` -- назначает белый или чёрный цвет в зависимости от того, регулярна нидинг-последовательность или нет  
`complexity` -- назначает цвет на основе сложности нидинг-последовательности (под сложностью понимается количество различных символов в последовательности)  
`periodicity` -- назначает цвет на основе сложности нидинг-последовательности, если эта последовательность регулярная. Иначе точке присваивается чёрный цвет 

**Задачи для детектирования типа симметрии аттрактора.** Создают карты режимов, на которых цвет каждой точки назначается в зависимости от типа симметрии аттрактора (T1, T2 или T4)

`symmetry_detectives` -- использует специальные функции, называемые «детективами симметрии»  

Другое:

`route` -- задача, которая строит заданный маршрут на карте нидингов. Имеет два режима: `attr` (отрисовывает аттракторы на маршруте) и `sepbif` (отрисовывает бифуркации сепаратрис при смене режимов на маршруте)
